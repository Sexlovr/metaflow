Streaming example
curl http://127.0.0.1:3117/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "meta-instant",          // or "meta-thinking"
    "messages": [
      {"role": "system", "content": "You are terse."},
      {"role": "user", "content": "Hello"}
    ],
    "stream": true
  }'
Models
meta-instantMuse Spark · MODE_FAST · ~2-5s responses
meta-thinkingMuse Spark · mode_thinking · reasoning stream + answer

Big contexts (> 24k chars) are automatically routed through the document-attachment pipeline (~500k token capacity, verified to 2MB). Thinking deltas stream as reasoning_content.
